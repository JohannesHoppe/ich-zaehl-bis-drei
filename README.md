# Ich zähl bis drei

**Der Familien-Pausenknopf.** Englisch: *Count to Three*.

Ein Knopfdruck am Smartphone oder Mac der Eltern, und auf dem geteilten Familien-iPad erscheint bei jeder App ein großer Hinweis: „Ich zähl bis drei – Spielzeit ist vorbei“. Ein weiterer Knopfdruck gibt das iPad wieder frei. Die Eltern sehen außerdem, ob die Sperre angekommen ist.

**Stand:** Das Projekt ist in der Planung. Es gibt noch keine App zum Installieren.

## So soll es funktionieren

- Auf dem iPad läuft eine native App, die über Apples Bildschirmzeit-Schnittstelle sperrt.
- Die Eltern steuern das iPad über eine Web-App, die auf Android-Smartphones und Macs läuft.
- Das iPad zeigt beim Einrichten einen QR-Code, den die Eltern einscannen.

Der Weg, auf dem Befehle vom Eltern-Gerät zum iPad gelangen, ist noch nicht festgelegt. Sobald er feststeht, beschreibt dieser Text, welche Daten dabei das Gerät verlassen und wer sie sehen kann.

## Was die App nicht kann

Es ist eine sanfte Sperre mit Nachweis, kein Schutz gegen jemanden, der den Gerätecode kennt. Wer ihn kennt, kann die Berechtigung in den Einstellungen widerrufen. Die App soll das den Eltern dann melden, verhindern kann sie es nicht.

## Warum der Quelltext öffentlich ist

Eine App, die ein Familiengerät sperrt, sollte nachvollziehbar sein. Deshalb kann jeder den Quelltext lesen. Das Projekt ist aber **nicht Open Source**: Weitergeben und Verändern erlaubt die Lizenz nicht.
